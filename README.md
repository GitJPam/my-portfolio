## 🔧 Personalización

### Cambiar el color principal
En `styles.css`, modifica:
```css
--primary-500: #3B82F6;  /* Cambia este HEX */
--primary-rgb: 59, 130, 246;  /* Y estos valores RGB */
```

### Actualizar links de GitHub y LinkedIn
En `index.html`, busca y reemplaza:
```
https://github.com/GitJPam
https://www.linkedin.com/in/juan-pablo-a-18717046/
```

### Agregar foto de perfil
Reemplaza `images/logo.png` con tu foto y ajusta el CSS del `.profile-avatar`:
```css
.profile-logo {
    width: 100%;
    height: 100%;
    object-fit: cover;  /* Añade esto para foto */
}
```
